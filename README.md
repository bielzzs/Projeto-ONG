# Projeto-ONG
ONG TransformAção - Plataforma Web 🌍🤝
Uma plataforma web completa e responsiva desenvolvida para modernizar a gestão e a presença digital de Organizações Não Governamentais (ONGs). O sistema conecta voluntários, doadores e a comunidade, facilitando a divulgação de projetos sociais, a captação de recursos e o engajamento cívico.

Este projeto é parte de uma atividade acadêmica de Engenharia de Software, focada na aplicação prática de arquitetura da informação, marcação semântica e acessibilidade web.

🚀 Funcionalidades e Personas
O sistema foi projetado para atender a quatro perfis principais de usuários:

Administrador: Gestão de informações institucionais, cadastro de projetos, acompanhamento de métricas, gestão de voluntários e prestação de contas.

Voluntário: Portal de descoberta de oportunidades, candidatura a projetos, histórico de participação e emissão de certificados digitais.

Doador: Acesso ao impacto dos projetos, acompanhamento de metas em tempo real, doações on-line e recebimento de relatórios de transparência.

Visitante: Exploração da galeria de atividades, acesso a informações de contato, missão e valores, e compartilhamento de conteúdo nas redes sociais.

🛠️ Tecnologias e Arquitetura
Fase Atual (Implementada):

HTML5 Semântico: Estruturação rigorosa utilizando tags apropriadas (<article>, <section>, <header>, <footer>, <figure>, <nav>) para SEO e acessibilidade.

Formulários Avançados: Implementação de validação nativa (Regex via atributo pattern), agrupamento lógico com <fieldset> e aplicação de máscaras de input em tempo real via pequenos scripts integrados.

Validação W3C: Código 100% validado sem erros de estrutura.

Próximas Fases (Roadmap):

CSS3 Avançado: Implementação de leiautes responsivos (mobile-first), uso de Flexbox/Grid e sistemas de design.

JavaScript Dinâmico: Consumo de APIs, interatividade de interface e manipulação avançada do DOM.
